# Legitimate-interest assessment worksheet

Uncompleted public template for deployments proposing that legal basis. No balancing test is concluded
and no organizational processing history or approval is asserted. The responsible reviewer determines
whether this basis is available for each purpose, participant group and jurisdiction.

## Purpose and necessity

Describe the specific interest and affected participants. Compare manual notes, minimized capture,
local processing and cloud processing. Explain why each data category, disclosure and retention period
is necessary; do not assert that an individual's prior practice proves necessity.

## Balancing and safeguards

Assess reasonable expectations, notice, sensitive data, employee/candidate power imbalance, potential
harm, objection handling and practical alternatives. Silence after notice is not automatically consent.
Verify participant-facing notice and stopping behavior; an organizer-only reminder is insufficient proof.
Record encryption/key handling, redaction limits, access restrictions, deletion, recovery and output-review
evidence using the [DPIA](dpia.md) and [recording policy](recording-policy.md).

## Local-model alternative to assess

The Qwen3.5 0.8B default is bundled with its GGUF/projector pair (763,759,712 bytes).
Optional Qwen3.5 4B requires explicit selection and a first-use download (3,584,533,344 bytes)
into the profile. Local AI is off by default and existing selections are preserved; hardware capacity
does not automatically select a larger model. Model downloads use commit-pinned upstream revisions
and byte-size/SHA-256 checks to validate the payload. The compact default is available offline on supported hardware; optional
4B offline use requires pre-placing verified files. A corrupt packaged default requires installer repair.
These source contracts do not qualify any historical release bytes or rewritten source.

## Decision to record privately

For each use case document the applicable basis, unresolved questions, required consultation,
restrictions, safeguard verification and responsible review. No positive outcome is prefilled.
Reassess before expanding to employee monitoring, employment decisions, automated publication or new
recipients. Inventory the actual network boundary in [data-flow-onepager.md](data-flow-onepager.md).
