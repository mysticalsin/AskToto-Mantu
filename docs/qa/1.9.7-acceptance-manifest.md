This manifest covers the approved **unsigned, manual-install 1.9.7 owner-channel prerelease**. Its acceptance target is the exact Windows Setup EXE and macOS DMG and their downloaded bytes. Signed stable distribution, notarization, Authenticode, and trusted automatic-update E2E are deferred and are not blockers for this milestone. Manual upgrade, data preservation, and recovery remain in scope.

The broader 2.1 roadmap and its 20-scenario mandate are separate. Nothing in this document marks 2.1 acceptance complete or imports its requirements as a 1.9.7 gate.

The legacy 1.8.10 checklist reference is stale context and does not supersede the approved 1.9.7 scope above.

## How to read this manifest

- **PASS** — the named criterion passed on the linked evidence revision. The row states what that evidence does and does not prove.
- **FAIL** — linked evidence records a failed required check, or the observed source behavior fails the criterion.
- **SKIPPED** — the named workflow explicitly skipped the check; skipped is not a pass.
- **NEVER RUN** — no exact candidate or report was found for the criterion at this snapshot.
- **BLOCKED EXTERNAL** — evidence requires a live service, owner-controlled account, or device readback that is not present here.
- **DEFERRED** — an explicit scope decision excludes the gate from this milestone; it is neither a pass nor a workflow result.

Evidence labels distinguish claims: **OBSERVED** is source/configuration or public-release inspection; **PROVIDED** is a linked hosted report or PR record; **DERIVED** is a conclusion from those facts; **UNKNOWN** is unverified. PR checks are not deployment evidence. The repo rule D-28 keeps repository tests, scripts, apps, builds, and formatters in GitHub Actions; this document change did not run them locally.
